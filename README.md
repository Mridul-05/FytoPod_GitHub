\# FytoPod: Predictive Plant Health Intelligence System



FytoPod is a multimodal AI-based plant health monitoring system for urban farming and indoor plants. It combines sensor-based stress prediction, image-based disease detection, disease spread forecasting, plant lifespan estimation, treatment simulation, and a unified plant health score.



\## Key Features



\- LSTM-based plant stress prediction

\- Image-based plant disease detection

\- Grad-CAM explainability

\- Plant lifespan estimation

\- Cellular Automata disease spread forecasting

\- Treatment impact simulation

\- Unified plant health score

\- AI-powered plant care assistant



\## Results



\- LSTM stress recall: 95%

\- Threshold baseline recall: 73%

\- Early warnings generated: 506

\- Average advance warning: 3 hours

\- Sensor data duration: 6 months

\- Disease classes: 19



\## Tech Stack



Python, TensorFlow, Keras, Scikit-learn, Pandas, NumPy, Matplotlib, Streamlit, FastAPI, PostgreSQL, Flutter, Groq LLaMA 3.



\## Dataset Note



The full PlantVillage-based image dataset is not included due to size limits. Only sample sensor data and result images are included.
